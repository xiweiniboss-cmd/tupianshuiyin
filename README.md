# 隐印 · 图片盲水印

单文件、纯前端的图片盲水印工具（DWT → DCT → SVD），图片不离开浏览器。把 `index.html` 放到任意静态空间即可部署。

## v2 改动
- 水印以“魔数 + 长度 + 文本 + CRC32”的帧写入，提取时不用再填比特长度，校验通过才算成功。
- 原始尺寸写入 PNG 元数据，并在写入后显示。
- 深度找回：在 Web Worker 中自动尝试常见缩放、翻转与 90° 旋转；重度压缩时改用亮度通道。
- 仍兼容旧版图片（填“旧版比特长度”即可）。
- 修复粘贴图片无效的问题。

## 抗截图版（kangjietu.html）
- 第二层平铺扩频水印（密钥生成的 128×128 图样）：截图、裁切、缩放、翻转、90° 旋转后自动对齐找回前 16 字节，CRC16 校验。
- 不同密钥的水印可以共存，别人用别的密钥重写盖不掉原水印。密钥要保密，知道密钥的人可以针对性抹除。
- 扛不住：任意角度旋转、对屏拍照的透视变形、截得太小（约 256 像素见方以下）、重度压缩或降噪。

## 已知局限（普通版）
裁边后又缩放（如截图）、任意角度大幅旋转、缩小叠加中等压缩、用同类算法重写覆盖，仍可能无法找回。

算法移植自 [guofei9987/blind_watermark](https://github.com/guofei9987/blind_watermark)（MIT License）。
