# 隐印 · 图片盲水印

单文件、纯前端的图片盲水印工具（DWT → DCT → SVD），图片不离开浏览器。把 `index.html` 放到任意静态空间即可部署。

## v3 改动
- 新写入的图把原来的帧（魔数 + 长度 + 文本 + CRC32）再用 Reed-Solomon 保护，藏进亮度的 16×16 平滑分块里。提取仍不需要原图。
- 深度找回会估计居中裁边、缩放、翻转和大约 ±28° 的旋转。水平翻转、90° 旋转可以对上；带白边扩出来的大约 15° 旋转，填上原图尺寸后可以对上。四边各裁约 10% 后再缩放、以及同画布小角度旋转，在平坦区域多的图上经常解不开。
- 手机截屏：深度找回会先找出纯色（黑 / 白）边框围住的图片区域，再扫描原图宽度、对位置和缩放做亚像素微调后解码，图上压着的按钮靠纠错扛过去。实测「标准」下缩到原宽约 23%～100%（含 JPEG 质量 70～90）不填尺寸可以对上；填上原图尺寸能到约 20%；再小就基本解不开。
- 写入时按截断后的 RGB 去凑每块的目标亮度，接近纯白、纯黑的块不再一写进去就是错的。旧版写的图，解码时会额外试一轮压低这些块的权重。
- 强度仍是轻 / 标准 / 强。标准抗到 JPEG 质量大约 20；质量大约 10 需要选强。强在平坦天空里可能略看得出。
- 写入前如果能提出已有水印，会先要求确认再覆盖。同一套方法再写一遍，读出来的是新的那行字。
- 旧版 v2（DWT-DCT-SVD）图片仍按原来的参数提取。

## v2 改动
- 水印以“魔数 + 长度 + 文本 + CRC32”的帧写入，提取时不用再填比特长度，校验通过才算成功。
- 原始尺寸写入 PNG 元数据，并在写入后显示。
- 深度找回：在 Web Worker 中自动尝试常见缩放、翻转与 90° 旋转；重度压缩时改用亮度通道。
- 仍兼容旧版图片（填“旧版比特长度”即可）。
- 修复粘贴图片无效的问题。

## 抗截图版（kangjietu.html）
- 第二层平铺扩频水印（密钥生成的 128×128 图样）：截图、裁切、缩放、翻转、90° 旋转及任意角度旋转（从自相关峰估计网格角度）后自动对齐找回前 16 字节，CRC16 校验。
- 不同密钥的水印可以共存，别人用别的密钥重写盖不掉原水印。密钥要保密，知道密钥的人可以针对性抹除。
- 扛不住：对屏拍照的透视变形、截得太小（约 256 像素见方以下）、重度压缩或降噪。

## 已知局限（普通版）
- 质量大约 10 的 JPEG，在「标准」下经常提不出来，需要「强」。
- 每边裁掉超过大约两成、对屏拍照的透视、缩到只剩一小块（截屏里图片宽度不到原图约两成），仍然会失败。截屏时图片区域和边框颜色太接近（比如黑底的图配黑边）可能找不准区域。
- 裁边后又改成另一个尺寸时，填上原始尺寸更稳。
- 用同一套方法再写一遍，会换掉这一次的字。写入前会先确认。

`node test/robustness.js` 用本页引擎做嵌入、JPEG、裁边、旋转和旧版兼容检查（需要本机有 Python Pillow）。

算法移植自 [guofei9987/blind_watermark](https://github.com/guofei9987/blind_watermark)（MIT License）。
